# 💊 Pharma Sales & Inventory Analytics

> End-to-End Business Intelligence Project using **Python, SQL Server, and Power BI**

## 📌 Project Overview

This project demonstrates an end-to-end Business Intelligence solution for analyzing pharmaceutical sales and inventory data. The objective is to transform raw transactional data into meaningful business insights that help improve sales performance, inventory management, profitability, and operational efficiency.

The project follows a complete analytics workflow:

**Raw Data → Python Data Cleaning → SQL Analysis → Power BI Dashboard → Business Insights**

---

## 🎯 Business Problem

Pharmaceutical companies generate large volumes of sales and inventory data daily. Without effective analysis, businesses face challenges such as:

- Poor inventory management
- Low-performing products
- Excessive discounts reducing profit
- Slow delivery performance
- Difficulty identifying top-performing sales representatives
- Lack of centralized reporting for decision-making

This project addresses these challenges through data analytics and interactive visualization.

---

# 🚀 Project Objectives

- Clean and preprocess raw pharmacy datasets using Python
- Perform business analysis using SQL Server
- Design a Star Schema data model
- Develop an interactive Power BI dashboard
- Analyze sales, inventory, products, customers, and profitability
- Generate actionable business insights for management

# 🧹 Data Cleaning (Python)

The following preprocessing steps were performed:

- Imported multiple CSV datasets
- Removed duplicate records
- Handled missing values
- Corrected data types
- Standardized column names
- Cleaned inconsistent values
- Formatted discount percentages
- Exported cleaned datasets for SQL analysis
